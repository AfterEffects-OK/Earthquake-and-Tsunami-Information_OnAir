# 地震情報ライブモニター（放送原稿作成機能付き）

P2P地震情報APIを利用して、リアルタイムで地震情報を表示・監視するWebアプリケーションです。
YouTube配信や放送業務での利用を想定し、テロップ表示や放送原稿の自動生成機能を備えています。

## 主な機能

### 1. 地震情報のリアルタイム監視
*   P2P地震情報APIから最新の地震情報を取得し、リスト表示します（デフォルトで震度3以上）。
*   リストから地震を選択すると、震源、深さ、マグニチュード、各地の震度詳細が表示されます。
*   表示モードは「市区町村別」と「観測点別」の切り替えが可能です。

### 2. 放送原稿の自動生成
*   選択した地震情報に基づき、アナウンサー読み上げ用の放送原稿を自動生成します。
*   **特徴**:
    *   難読地名へのふりがな自動付与（気象庁データ + 手動辞書）。
    *   原稿プレビュー画面での「白黒反転（ダークモード）」「全画面表示」「文字サイズ調整」機能。
    *   「閉じる」ボタン、「ページのトップへ」ボタンによる操作性向上。

### 3. 放送用固定バー（テロップ表示）
*   画面下部に、テレビ放送のような固定情報バーを表示します。
*   **自動ページ送り（オートプレイ）**: 震度速報や各地の震度情報を自動で切り替えて表示します。ループ再生にも対応。
*   **トランジション効果**: スライドやカットなどの切り替え効果を選択できます。

### 4. 津波情報・緊急地震速報 (EEW) 対応
*   **津波情報**: 大津波警報・津波警報・注意報の発表状況や、津波観測情報を表示します。
*   **緊急地震速報 (EEW)**: 速報受信時にアラートを表示し、通知音を再生します（通知音はカスタマイズ可能）。
    *   **表示テスト**: 画面右上（タイトルの右側にある空きスペース）のEEW表示エリアにマウスカーソルを合わせると、右上に「TEST REAL DATA」ボタンが表示されます。これをクリックすることで、実際のデータ形式での表示と通知音のテストが可能です。 

### 5. 訓練モード
*   過去の大地震（関東大震災、東日本大震災など）や想定地震（南海トラフ地震など）のダミーデータを使用して、動作確認や避難訓練のシミュレーションが可能です。

### 6. その他の機能
*   **Google Apps Script (GAS) 連携**: 取得した地震データをGoogleスプレッドシートに自動記録できます。
*   **ふりがな辞書管理**: 地名の読み仮名を修正・追加できる辞書編集機能を搭載。インポート/エクスポートも可能です。
*   **キーボードショートカット**: オートプレイの制御などをキーボードから操作できます。

## 使用方法

### 地震一覧パネル（左側）
*   **地震リスト**: 取得した地震情報が時系列順に表示されます。クリックすると詳細が表示されます。
*   **API更新ボタン**: 手動で最新情報に更新します。
*   **訓練モードボタン**: 訓練用ダミーデータの表示/非表示を切り替えます。
### 地震詳細パネル（右側）
*   **詳細情報**: 震源地、深さ、マグニチュード、津波の有無、各地の震度が表示されます。
*   **表示切替**: 「市区町村別」と「観測点別」の表示モードを切り替えられます。
*   **放送原稿を作成**: クリックすると、別ウィンドウで放送原稿ページが開きます。
### 情報表示バー（画面下部）
選択した地震情報をテロップ形式で表示するエリアです。
*   **再生/停止**: 情報ページの自動送りを制御します。
*   **ページ送り**: 手動で前後のページに移動できます。
*   **設定**: ループ回数やページ表示時間を変更できます。

#### OBSでの表示方法（推奨）
情報表示バーの右側（コンテンツ表示エリア）は、背景が**透明**になるように設計されています。
OBS Studioなどの配信ソフトでクロマキー合成を行うことなく、簡単にテロップとして利用できます。
1.  OBSで「ソース」を追加し、「**ウィンドウキャプチャ**」を選択します。
2.  キャプチャするウィンドウとして、このアプリケーションが表示されているブラウザを選択します。
3.  ソースのプロパティを開き、「**透過を許可**」のチェックボックスをオンにします。
    *   *注意: ブラウザのハードウェアアクセラレーション設定によっては透過が効かない場合があります。*
4.  `Alt`キーを押しながらソースの境界をドラッグし、画面下部の情報表示バーのみが映るようにクロップ（トリミング）します。

### 放送原稿ページ
「放送原稿を作成」ボタンから生成されるページです。アナウンス読み上げに特化しています。

*   **ふりがな付き原稿**: 震源地や市区町村名に自動でふりがなが振られます。
*   **表示カスタマイズ**:
    *   **白黒反転**: 画面右上のボタンでダークモードに切り替え可能。
    *   **全画面表示**: 原稿をモニターいっぱいに表示します。
    *   **閉じるボタン**: ウィンドウを閉じます。
    *   **トップへ戻る**: 長い原稿のスクロールを補助します。
*   **原稿構成**:
    *   発生日時、震源地、深さ、マグニチュード
    *   津波の有無（警報・注意報の内容）
    *   震度ごとの地域リスト（震度の大きい順）

### 設定モーダル
画面下部操作パネルの「歯車アイコン」からアクセスできます。
*   **再生/停止ショートカット**: テロップの自動再生を制御するキーボードショートカットを設定できます。
*   **緊急地震速報(EEW)設定**:
    *   通知音のON/OFF切り替え。
    *   **音声出力先**: 通知音を再生するスピーカーデバイスを選択できます。
    *   **カスタム通知音**: 任意の音声ファイル（MP3/WAV等）をドラッグ＆ドロップで登録し、デフォルト音の代わりに使用できます。
*   **表示フィルタ設定**:
    *   **情報画面に表示する最低震度**: テロップで再生する地域の最低震度を設定します（例: 震度4以上のみ表示）。
    *   **地震一覧のフィルタ**: 左側リストに表示する地震の最低震度を設定します。

### ふりがな辞書モーダル
画面下部操作パネルの「辞書アイコン（本のマーク）」からアクセスできます。

*   **手動登録**: 読み方が特殊な地名や、自動付与が間違っている場合に、正しいふりがなを手動で登録・修正できます。
*   **インポート/エクスポート**:
    *   登録した手動辞書データをJSONファイルとして保存（エクスポート）したり、読み込んだり（インポート）できます。
    *   **気象庁自治体辞書を出力**: アプリが内部で使用している気象庁データのふりがな辞書をJSONとして出力できます。

## 3. 仕様詳細

*   **データソース**:
    *   P2P地震情報 API v2 を使用。
    *   取得コード: `551` (地震情報), `552` (津波予報), `554` (緊急地震速報), `556` (津波観測情報)。
*   **更新頻度**:
    *   自動更新: 2分間隔。
    *   手動更新: ボタン操作時。
*   **データ処理**:
    *   **ID生成**: `発生時刻` + `震源地名` のハッシュ値を用いて、APIのIDに依存しない安定した一意のIDを生成・管理しています。
    *   **情報マージ**: 同一地震に対する複数の更新（速報値→確報値、観測点の追加など）を自動的にマージし、常に最新かつ詳細な情報を保持します。
*   **設定の保存**:
    *   各種設定（ショートカット、通知音、辞書データなど）はブラウザの `localStorage` および `IndexedDB` に保存され、次回アクセス時も維持されます。

## 4. 動作環境

*   Google Chrome, Microsoft Edge, Firefox などのモダンブラウザ。
*   インターネット接続が必要です。
